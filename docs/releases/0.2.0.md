# 0.2.0

- Complete local contact groups/pictures/ringtones, music playlists, VFS copy/move, image/video browsing, common settings and calendar reminders.
- Recover the original SF2 bank and Snake MIDI resources; synthesize locally with shared ringtone controls and bounded background audio work.
- Recover the Snake RNG update and retain explicit limits for the initial seed and native behavior.
- Keep the modular winit/wgpu application and optimized macOS bundle. Version metadata now comes from the Cargo workspace, including `--version` and both bundle version fields.

Validation before this release: 127 default tests, warnings-denied Clippy, real CoreAudio output/mute/stop and 118 Metal screenshot routes. These checks do not establish full handset parity. See [remaining scope](../remaining-work.md), [audio evidence](../native-audio.md) and [validation](../validation.md).

Session data persistence, including snoozed alerts and running utilities, is the next pass. Calls remain disabled; SMS has no modem backend.
