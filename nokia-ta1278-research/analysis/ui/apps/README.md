# 面向功能机交互复刻的应用交付

本轮把静态资源进一步连到应用事件、菜单动作、返回分支和可测试的状态模型。优先阅读 [短信规格](sms-contract.md)、[浏览器规格](browser-contract.md)、[音乐规格](music-contract.md)，再接入 [纯状态参考实现](../../../tools/app_interaction_reference.py)。**这是可用于开发复刻系统的合同与原型逻辑，不是完整恢复的原机源码，也不是已完成的图形模拟器。**

输入是本机 `17.00.17.02` 的 `user.bin`，SHA-256 `8f0db2dc82f9e763cb700c2e5781b7ca7125a4d250f4c075dbec793eb549c1ca`。所有 `0x88……` 地址均为 `0x88000000 + user.bin 文件偏移`，包含 DHTB 头。只读取已有系统工作副本，没有再次连接手机或读取私人分区。

## 如何理解证据

- **A 原生证据**：原始表、立即数、指针和可追踪的条件分支。它证明编译进镜像的路径，不自动证明当前地区配置会进入该路径。
- **B 关联解释**：相同函数日志/调用形状与固定版本公共框架源码相符。跨版本解释，不能直接移植枚举或条件编译开关。
- **C 外部行为依据**：已收录的 Nokia 官方用户指南；见上一级 official-behavior-baseline.md。
- **P 复刻策略**：让新系统行为闭合的明确设计选择。可以开发、测试，但不能回写成 Nokia 的已证实行为。

最重要的边界是：**完成复刻规格的状态覆盖，与原机逻辑恢复率是两件事**。未得出有依据的总体百分比。窗口数量、测试通过数和函数数量不能换算成恢复率。

最新增补：[本机算法](native-algorithms.md)，含 8 组短信容量、19 个重试原因、22 项浏览器异步消息、地址/认证流程和音乐中心键回调链。小规则可独立运行，完整应用模型仍保留 P 标记。

## 复刻系统的模块边界

1. **Input** 接收物理 key down/up/long down/long up；按上一级 key-event-map.json 转换。不要让网页浏览器默认 key repeat 代替原机方向事件。宿主键盘到软键的映射由复刻程序声明。
2. **Window stack** 保存应用窗口、弹层、返回目标、焦点控件、滚动位置。任何弹层关闭后恢复原焦点；页面和发送的异步结果带操作 ID。这个返回栈管理策略为 P，不声称已解完原生 MMK。
3. **Text editor** 使用 UTF-16 位置、选区和独立的未提交多击候选。正文、收件人、URL、网页字段复用编辑内核，限制和输入模式分别配置。
4. **Renderer** 以 240×320 为复刻画布，读取真实字体、图标、文案和颜色；输出可视行边界与焦点矩形给状态机。顶栏/软键栏高度、基线和换行像素仍需测定，不能把随意画出的手机框当原机验收。
5. **Services** 把短信发送、网页加载/表单/下载、媒体播放隔离为接口。当前参考实现只有合成结果，没有真实短信、HTTP 或音频后端；无需基带模拟便可开发交互层。
6. **Storage** 新系统定义自己的联系人、草稿、历史、书签、播放列表格式。原机文件系统/私有数据库格式不是复刻这些交互的前提。模型当前仅内存存储，真实持久化需适配器及失败处理。

## 开发顺序与验收

第一步搭好共用窗口栈、软键条、列表焦点、弹层和编辑器，接入提取字体。第二步完成短信从文件夹到编辑、草稿、发送结果的闭环；第三步接浏览器地址页、菜单、历史和字段编辑，先使用固定测试页面。第四步接音乐队列与媒体适配器。

每个功能建立三列验收：**原生字节/控制流复核**、**复刻模型用例**、**实机或视频行为对照**。本轮前两类有结果，第三类未开展。不能以模型用例通过替代手机验收。

从项目目录运行：

```sh
python3 tools/rebuild_app_analysis.py
```

前提是已按仓库说明恢复系统工作副本及原有 UI 分析结果；反汇编依赖现有 macOS Xcode `xcrun llvm-objdump`。不需要安装新包。原有 14 步资源流水线仍独立；现有 7 步应用流水线。仅运行模型测试可用 `python3 tools/test_app_contracts.py`，其中原生证据测试需要已有工作副本和 JSON。

隔离复现也已通过：从 Git 可见文件导出到临时目录，只准备发布的系统原件，重新生成合成 ELF，删掉应用生成物后重跑；79 个确定性输出逐字节一致，75 项检查通过。63 份参考文本在 SHA 核验后复制，未导入私人 NAND/NV。见 [复现记录](reproduction-validation.json)。
