# 浏览器应用交互合同

本合同的 A 级应用路径属于 **Dorado 浏览器分支**。本机同时含 Native Opera Mini 字符串和另一启动路径，入口设置 `0x286` 的实际取值未读；因此不能把以下行为无条件等同用户在这台手机上看到的默认浏览器。复刻时将引擎配置独立命名，保留替换能力。

## 窗口和原生入口

此前只按调试名称索引，漏掉了 0x6 组的大量无名窗口。按原生 ID 组索引后得到 **40 个描述片段**，包含主页、页面、地址输入、认证、下载等；完整属性见 application-resources.json。窗口描述片段不等于全部可达屏幕。

| 窗口 | 描述偏移 | Handler | 依据/用途 |
|---|---|---|---|
| 60001 | 73ef20 | 88b6483d | 起始页 |
| 60002 | 73ef98 | 88b649c5 | 起始菜单 |
| 60004 | 73eb44 | 88b61ff3 | 页面主窗口 |
| 60006 | 73ec64 | 88b6361d | 页面菜单 |
| 60007 | 73eb94 | 88b62a69 | URL 编辑；EDIT 参数 0x200、控件 60099 |
| 60008 | 73ebcc | 88b62ce1 | 认证相关 |
| 60016 / 60017 | 73ec98 / 73ecd0 | 88b639b5 / 88b63a95 | 用户名/密码编辑，构造容量各 0x14，控件 60066/60067 |
| 6001e | 73ed00 | 88b61525 | 下载窗口候选，关联源和回调 |

Handler 表中的最低位 1 为 Thumb 标志，反汇编入口应清掉它。编辑容量是构造参数，后续是否调整未证明；不要把 512 UTF-16 单元误写成 URL 网络字节限制。

## 原生菜单结构

`user+73e80c` 起是 **每项两个 u32：动作 ID、文字资源 ID**。本机是非 PDA 形状，不是三列带图标的数组。各数组原始字节 SHA 和三语言标签见 native-menus.json。

| 菜单 | 顺序（ID : 英文标签） |
|---|---|
| 页面 | 5 Open；28 Navigation；29 Save；10 Download management；7 Share link；23 Page details；3 Settings；13 Close |
| Open | 15 Home page；14 Enter URL；8 Bookmark；9 History；11 Offline pages |
| Navigation | 19 Refresh；16 Stop；17 Forward；18 Back |
| Save | 20 As home page；21 Bookmarks；22 Webpage；31 Image |
| 起始页菜单 | 15 Home page；3 Settings；13 Close |

父级 Open/Navigation/Save 的动作在页面选中处理器中落默认块，因为子菜单由菜单控件处理；不能因此删掉这些菜单。动态启用条件需结合请求状态、历史与页面内容。ID 32 还有原生跳转，但不在上面五张菜单表中，本轮不赋予无证据的功能名。

## 键盘、按住与滚动

页面 handler 32 个非默认 event ID 见 event-routes.json，原生锚点如下。

| 输入 | 即刻调用 `883b4d86(instance, code)` | 按住 timer 调用的 code |
|---|---:|---:|
| 上 fa01 | 14 (`88b6237a`) | 18 (`88b62538`) |
| 下 fa02 | 15 (`88b623a2`) | 19 (`88b6255e`) |
| 左 fa03 | 12 (`88b623ca`) | 16 (`88b6253c`) |
| 右 fa04 | 13 (`88b623f2`) | 17 (`88b62540`) |
| 中软键 e004 / WEB fa1b | 20 (`88b6240c`) | 无对应方向 repeat |

第一次方向按下启动 timer，参数 500；timer 匹配后检查窗口焦点和有效实例，重复分支重新设置参数 100（`88b62548`）。抬起 fb01…04、长按抬起 fd01…04 及失焦 f023 共用清理路径 `88b62334`，停止 timer 并清空保存的按键状态。单位未闭合，参考模型使用“timer units”，不能标成实测毫秒。

另有 e090…e094 滚动控件消息分支（up/down one、page、move 的名字为 B）。Dorado 引擎如何根据 HTML 元素位置决定焦点/滚动，仍在 `883b4d86` 及渲染引擎内部，不等于已经恢复了“方向键移动固定像素”。复刻的网页引擎应返回焦点矩形、scrollY、编辑字段和动作；UI 层传递原生区分后的键盘事件。

## 返回键的三个条件

页面 Cancel/右软键 `e002/fa17 → 88b62486`：

1. `8835c3cc` 返回有请求状态时，调用 `883b3f28`（与公共 StopPageReq 形状/日志关联）。成功后清请求状态并刷新 UI；不直接退出浏览器。
2. 没有请求时，`880bda40` 读取当前页面对象 `+204`，判断后退能力；有则 `883b5408(instance, 1)`。Forward 查询 `880bda54` 读 `+208`，动作使用参数 2。名称由菜单/代码联合关联。
3. 没有可后退页面时，建立询问窗口，文本 `40060049` **Close current page?**。具体确认回调和所有窗口栈清理未完全闭合，复刻默认确认返回起始页，取消留在页面，标 P-BRW-STACK。

这三个条件的优先级不能合并为一个 browser.history.back()。参考模型还规定弹层优先关闭，这是 P 的窗口栈策略；它不改变上面主页面 handler 的原生三个分支。

## 状态合同

数据至少包含：起始/页面状态、当前页面、历史索引、请求 ID、请求是否进行中、页面滚动/焦点、地址编辑缓冲、字段编辑缓冲、弹层、认证挑战、下载任务、书签和离线页。

| 状态/事件 | 结果 | 证据 |
|---|---|---|
| 起始页/地址确认 | 非空地址交给页面加载；空地址不请求 | `0324 → 88b6242c` 校验，地址窗口关联 A/B |
| 页面/普通方向 | 发送普通键码，设置首次 timer | A |
| 页面/timer、仍聚焦 | 发送持续键码，重新设置 timer | A |
| 页面/失焦或方向释放 | 清按住和 timer | A |
| 页面/中心键 | 发送引擎 code 20；由引擎决定链接/字段/控件 | A；节点语义为引擎接口 |
| Loading/返回 | 停止当前请求，保留已有可显示页面 | 停止 A；保留页面/错误回退细节为 P-BRW-ASYNC |
| 页面/返回 | 有历史发起后退；无历史问关闭 | A/B |
| 关闭询问/取消 | 留在页面 | P-BRW-STACK |
| 地址/字段/菜单弹层/返回 | 撤销未确认缓冲，恢复原页面焦点和滚动 | P-BRW-STACK |
| 加载成功 | 替换或追加历史；跳到新页面焦点 | P-BRW-ASYNC，历史更新时点未从引擎完全恢复 |
| 加载失败 | 保留旧页；显示失败，可重新输入或重试 | P-BRW-ASYNC |
| 请求被取消/替换后旧结果到达 | 忽略，不覆盖新页 | P-BRW-ASYNC |
| 链接选中 | navigate(href) | P 的页面适配器；原生仅确认 code 20 |
| 输入框/密码/选择框 | 弹出编辑；确认写回字段，取消不变 | P 的页面适配器；原机字段资源/窗口提供 B 线索 |
| Checkbox / Submit | 切换值 / 返回表单描述给网络适配器 | P 的页面适配器 |
| 保存书签/离线页 | 保存 URL/标题或离线快照 | 菜单 A；保存格式与失败流程 P |

P-BRW-ASYNC 的新导航会截掉当前索引之后的 forward 历史；刷新/后退更新目标位置；操作 ID 只接受当前请求。P-BRW-STACK 关闭页面回起始页但保留模型历史；是否清历史可作为配置，原机行为尚未确定。

本轮模型覆盖上表基本页面流程和字段/书签/离线快照。认证重试、下载中断/继续、网络设置、文件选择、图片保存、页面详情、链接分享到短信只提供下面接口合同，未实现成实际后端。

## 后端与完整复刻接口

浏览器复刻不应依赖已经不可用的历史代理服务器。可选一个现代宿主浏览器后端，或者固定页面/简化 HTML 后端；这些都必须标 P。保留原机 UI 的菜单、焦点和按键行为，再明确不兼容的网页能力。

- `navigate(url, operation_id, history_target)` → progress/success/failure。成功附页面标题、URL、滚动范围、焦点图和可编辑字段；进度不自动等于导航完成。
- `activate(node_id)` → link / form / field / download / no-op。表单的 GET/POST、字符编码、cookies、证书由引擎后端决定，状态层不猜测。
- `auth(challenge_id)` → 认证编辑，确认重新提交当前挑战，取消终止挑战；密码只存在新系统的运行态，不在研究日志记录。
- `download(task_id)` → pending/progress/completed/failed/cancelled；退出菜单不等于取消下载。后台是否继续为 P 配置。
- `share(url)` → 新建短信的正文缓冲；成功进入编辑后保留返回浏览器的上下文，发送行为仍走短信适配器。
- `save(kind, data)` → 成功/空间不足/失败；失败应保留页面和用户输入。

方向焦点推荐策略属于 P：先使用宿主提供的语义焦点顺序；需要空间导航时在目标半平面选候选矩形，主轴距离优先，再用次轴距离打破平局；没有候选则滚动。具体评分、滚动量、wrap 与页面折行不能冒充原始 Dorado 算法，本轮模型故意不伪造它。

## 验收和未决

已验证合成轨迹：加载中 Back 停止；历史 Back；根页面关闭确认；旧请求结果忽略；历史分叉；失败保留旧页；四方向普通/持续键码与释放；字段确认/取消；链接/checkbox；书签及离线副本。

仍未恢复：Opera Mini 的对应状态机、原机默认引擎和地区选择值、Dorado 完整页面布局/焦点算法、JS/HTML 支持范围、网络错误全枚举、证书与登录行为、下载任务恢复格式、精确等待动画时序。没有进行真实网页或手机浏览器验收。新系统可按上述明确接口完整搭建基本交互，但不能声明所有网站表现与原机完全一致。
