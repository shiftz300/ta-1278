# 后续交互程序

必要离线调查已按 [收尾范围](../replica-readiness.md) 结束；完整原机逻辑仍有明确未知项。私人和临时文件已归档到工作区外的 `ta-1278-source/` 并核验哈希。模块化 Rust 程序已实现，详见仓库根 README、`docs/architecture.md` 与 `docs/validation.md`。私人 NAND/NV 不作应用资源。

- Rust；窗口、宿主输入和事件循环使用 **winit**，渲染使用 **wgpu**。
- 鼠标按按钮映射：**左键→左软键，右键→右软键，中键→确认键**。不是点击画面区域；点击须产生手机按键事件，不只激活窗口。
- 键盘与鼠标经过统一的按下/释放输入层。窗口失焦时清理按住状态；具体宿主快捷键在实现时写明。
- 电话和短信只做逻辑测试，服务接口留空；不得发送真实短信或拨号。浏览器可以做简单实现，需标明与原机引擎的差异。
- 拆分宿主窗口、渲染、资源加载、输入、窗口栈、文本编辑、短信、浏览器、音乐和服务适配器，避免单个大文件。
- 复刻策略与已恢复行为分别标注；winit/wgpu 的可运行界面不作为逆向完成证明。
