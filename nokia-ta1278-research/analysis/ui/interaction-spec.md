# 复刻可用的交互实现依据

应用流程的新一轮扩展见 [短信、浏览器与音乐复刻合同](apps/README.md)，包含 22 段定向反汇编、原生菜单/跳表、返回和保存路径及明确标为 P 的复刻策略。

输入版本 17.00.17.02；地址为本机 user.bin 的 `0x88000000 + 文件偏移`，包括 512-byte DHTB 头。本文件只规定有依据的局部行为。A 为本机原字节/控制流，B 为公共框架相关推断，C 为官方用户指南；未决项不赋予默认行为。

## 按键转换

`0x882e2e9c` 的信号处理路径调用 `0x88135052`，查 `user+0x4acb58` 的 105-byte 表，再经 `0x8813502e` 的 12 对重映射。先归一化扫描信号 `24→0a、25→0b、66→5f`（十六进制），截为低 8 位，取首个匹配的表索引；没有匹配返回 0。19 个已配置矩阵键均找到有效 UI 代码。A。

| 扫描值 | UI 代码 | 按下事件 | 名称（B） |
|---|---|---|---|
| 04 / 05 / 06 / 07 | 01 / 02 / 03 / 04 | fa01 / fa02 / fa03 / fa04 | 上 / 下 / 左 / 右 |
| 01 | 05 | fa05 | 拨号 |
| ASCII 1…9 | 08…10（十六进制） | fa08…fa10 | 数字 1…9 |
| ASCII * / 0 / # | 11 / 12 / 13 | fa11 / fa12 / fa13 | 星号 / 零 / 井号 |
| 08 / 09 | 16 / 17 | fa16 / fa17 | 左软键 / 右软键 |
| 02 | 18 | fa18 | RED/结束；独立电源路径未核实 |
| 0d | 1b | fa1b | 框架名 WEB；与中软键通知共享消息处理块，但矩阵未列该信号 |

`fa/fb/fc/fd/fe` 前缀在原生分发中存在；公共命名依次为按下/抬起/长按下/长按抬起/重复。不能把长按阈值或事件顺序从别的设备移植过来。精确表、二次重映射和矩阵坐标见 [key-event-map.json](key-event-map.json)。

## 输入和编辑

- 147 张候选字符表，每张 12 行，每行 u16 数量和最多 39 个 UTF-16 单元。模式注册有 781 项，不能视为 781 种实际启用输入法。A。
- 多击时同键轮换当前候选；换键提交前一个；显式提交事件之后同键追加；回绕到第一项；空 slot 不改文本。有一张表的 0 键项为“空格、0、LF”。参考实现及六类用例在 [interaction_reference.py](../../tools/interaction_reference.py)。该表的行为不等于所有语言都直接用 0 插入换行。A。
- 提交计时路径参数为 750；单位和定时器换算未确认，不写死为 750 ms。A。
- 编辑器对象中 `+90` 为文字缓冲指针，`+94` 长度，`+ae` 光标，`+c2/+c4` 选区端点；偏移为十六进制。选区方向、额外范围对象必须保留，不能简化为一个 JS 字符串索引。A。
- 光标分发 `0x882ffe3c` 的方向 1/2/3/4 对应上/下/左/右；水平处理 `0x882ffaa0`、垂直处理 `0x882ffd36`。方向名由匹配的框架代码与原生分支关联。B；行宽、折行与几何需原生渲染信息。
- 退格 `0x880951fa`：有选区先删除选区；光标 0 不删；通常删除一单位；某范围对象条件可删除两单位。后者来自 `0x88095f98` 的范围对象匹配，不是已经证明的 Unicode 代理项检查。A。
- SMS 底层 `0x88b50d34` 出现 160/153 和 140/134 容量；`0x88b50ec4` 处理段末 ESC。尚不能完整推导 UI 的中文剩余字数、多段提示和每种字符转换；70/67 不能未经路径证明就写成该固件实测行为。A + 未决。

## 新建信息结构与事件

窗口 `0x7000c`，描述 `user+0x227790`，处理 `0x8839962a`；标题为 New message / 新建信息 / 新訊息。11 个子控件的 ID、父子关系和数值为 A；以下类型/参数名为 B。

| 节点 | 类型及已知参数 | 父节点 |
|---|---|---|

| 70079 | EDIT_LIST，100 项、每项 40 单位 | 70078 |
| 70091 | 横向 FORM | 70071 |
| 7007f | 纵向 FORM | 70091 |
| 70092 | 非背景、不可聚焦 ANIM | 7007f |

构造容量不是消息最终长度上限；没有坐标的 FORM 不应被伪装成已恢复的像素布局。

| e002 / fa17 | 88399ed4 | Cancel / 右软键共用分支；已补候选列表优先关闭、条件草稿保存，见 apps/sms-contract.md |

## 主屏、菜单、浏览器与跨应用状态

主菜单 `user+0x21cf2c` 是 30 个 24-byte 注册项，关联 label/icon/Thumb handler/parameter；它不是运行时完整菜单树。窗口描述的 callback/ID 前缀和控件树已索引；晚期 opcode 存在跨版本差异（公开 END_WIN=f031，本机=f032），本机 f031 故意不命名。

Internet 入口 `0x880bce3e` 读取设置 ID `0x286`，按结果选 `0x880bce1a` 或 `0x880bcdf6`，最终进入共用启动函数 `0x882eaa8e`。这证明存在条件启动路径，尚不能把某值唯一命名为默认引擎。固件还含 Native Opera Mini/4.4.34868/hifi/oem_nokia、Dorado WAP-Browser/1.0.0 及解析/渲染源路径；均在 [字符串证据](browser-input-string-evidence.json) 中保留偏移。A。

主屏→Menu→应用，New message→收件人→正文→Send，以及浏览器地址输入可按 [官方行为基线](official-behavior-baseline.md) 建立 C 级交互骨架。焦点环绕、状态栏尺寸、返回栈、弹窗、网络失败和持久化规则目前无法由这些资料完整恢复，必须作为待验证项或明确的复刻设计选择。不能把本规格叫作完整原机状态机。
