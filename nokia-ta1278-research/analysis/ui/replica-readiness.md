# 必要逆向收尾与实现边界

2026-10-25。针对可操作的本地交互程序，本轮必要离线调查收尾。不是整个原机操作系统或所有交互均已还原；无法确认的项目保留在 reverse-engineering-status.md，不用猜测填成事实。

| 功能 | 可直接使用的证据 | 程序中的明确设计选择 |
|---|---|---|
| 显示、菜单 | 240×320、已提取字体和图标、30 项入口注册 | 选取短信/浏览器/音乐/电话/联系人/设置；布局、顺序、滚动和返回栈由宿主实现，非像素级还原 |
| 输入 | 矩阵转换、多击字符表、按下/释放/长按事件 | 750 ms 多击窗口、500 ms 长按；原生时间单位未证实。桌面可直接输入字母和中文 |
| 短信 | UTF-16 编辑、选择优先删除、字符分类、剩余数/段数、保存与退出流程 | 默认编码配置 management=1, encode=0；本地草稿/待发箱；无调制解调器、SIM 或真实发送 |
| 浏览器 | 地址/字段/选择框事件、停止→后退→关闭、表单分发 | HTTP(S) 文本浏览器；HTML 文本、链接、输入框、复选框、选择和 GET 表单；不复制 Dorado 排版、JavaScript 或 WML 引擎 |
| 音乐 | 短按切歌、长按快进退、播放暂停、循环模式、自然结束 | 合成曲目及进度用于逻辑测试；不声称恢复音频服务和原机 shuffle 序列 |
| T9 | 已确定版本、词库块及部分目录 | 候选查询/排序未恢复；不提供冒充 T9 的候选算法，使用已恢复多击表 |

完整原机还原仍需要原屏布局/时序对照、T9 引擎继续分析、Dorado 内核、后台服务及地区配置验证。这些不阻塞用户要求的无电话/短信后端基础交互程序。以后发现行为偏差，按可复现轨迹回到对应原生函数定点分析；不再无差别遍历驱动、基带和整个网页引擎。

证据：apps/interaction-core.md、apps/native-algorithms.md、apps/*-contract.md、multitap-tables.json、key-event-map.json。75 项既有参考模型检查及 79 项重建产物一致性是静态/模型验证，不是实机行为验收。
