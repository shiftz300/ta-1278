## 新解出的格式与证据

### SJPG

11 个文件头为 12 字节：`SJPG`，大端 u16 高、宽、采样标记、质量标记。样本采样标记 3 对应 4:2:2；质量标记 0/4 分别使用与标准 JPEG 质量 40/95 一致的量化表。重建所用亮度/色度量化表在本机 kernel 的 `0xbc6720 / 0xbc6860`、`0xbc6820 / 0xbc6960` 逐字节匹配，四份 Huffman 表的计数/符号也全部匹配原生数据。

独立 Huffman 遍历检查每个 MCU、系数 run 边界、字节填充与完整输入消费；末尾 0–7 位的实际填充值保留，没有错误地要求它全为 1。重建 JPEG 及 PNG 可正常加载，壁纸联系表已目视核对。Pillow 的 IDCT 与颜色转换舍入仍可能不同于手机。[解析器](../../tools/decode_sjpg.py)、[联系表](sjpg-contact-sheet.png)。

剩下两个无预览条目是 28-byte `user` 名称记录：`IMAGE_TITLE_BAR`、`IMAGE_COMMON_BG`，不是含像素的普通图片。当前推测由代码绘制或动态绑定，尚未找到并验证完整绘制路径，不能凭名称补成原厂背景。

### 通用 DATA、COLOR、RECT

旧索引将类别 6 命名为 `wap_presets`，现在确认应为通用 DATA：既有 OTAC/BKMK/MTVA，也有 T9。类别 7/8 分别对应 COLOR/RECT。旧切片文件名为兼容旧流程保留，不能继续据旧标签把整块解释为网络预置。

DATA 描述为 12-byte flags/size/group-relative-pointer，479 项全部检查容器边界。COLOR 为 8-byte RGB565 值和有效标志；55 项与 CSCS 名称关联。RECT 为四个 int16 和 u32 有效标志；3 个矩形不能直接认定为屏幕布局坐标。[提取器](../../tools/extract_data_resources.py)。

### T9

固件 `user+0xcc3d4 / 0xd7704 / 0xe5030` 含明确 T9/T9CC/T9AW 版本，故不再只是 Smart9Key 字符串猜测。英文语言 ID `0x0109` 的两组三块文件各拼为 36,651 字节，内部 trie 尚未解码。

简体 `0x0204` 的 192-byte 头来自初始化 RAM `0x81c6e3f8`；66 槽中 15 个有效块，与原生 `0x8854c758..0x8854ca32` 的 DATA 加载/指针填充关系及所有长度吻合。已重建含外部偏移目录的容器；它是派生研究文件，不冒充原厂独立 LDB 文件。头部标志含笔画、部件、拼音和 context40。

繁体 `0x0104` 两套头候选位于 `0x81c6e5c0 / 0x81c6e788`；按目前加载映射有 5/4 项长度不匹配。可能涉及变体或布局解释差异，尚无充分证据判定原因。仅导出原始块和头，不生成虚假的完整繁体容器。词条、候选排序、自学习、联想和实际语言选择尚未恢复；未读取个人词库。公开 T9 头文件仅用于格式关联，未执行原生引擎校验。

## 公开资料如何补充

官方 2020 版指南明确列出 TA-1278，能支持普通导航、输入、发送流程；不能确认此固件地区变体的每个动态分支。公开 W19 MMI 源码只作跨版本关联，已发现 END_WIN 和本机短信菜单编号不同，故不能整套照搬。详细链接和可信度见 [公开行为基线](official-behavior-baseline.md)、[来源](../../sources.md)、[49 个源码文件的固定版本/哈希](../../tools/upstream-reference/mmi-framework/provenance.json)。

复刻时可直接复用字体轮廓、素材、文案、颜色、多击表和已验证的输入算法；其余实现必须保留“公开资料推断”或“复刻设计选择”标记。本项目没有生成冒充原机逻辑的完整模拟器。

项目根目录执行 `python3 tools/rebuild_offline_ui.py`。14 步均通过；资源和控件逐字节回查、源组件 SHA、612 个增补帧哈希、2,824 个预览加载、3 个重建词库容器和全部 22,349 字形均有对应检查。六类多击参考用例通过。完整结果见 [验证](validation.json)、[框架关联校验](framework-semantics-validation.json)、[流水线](rebuild-log.json)。

这证明解析结果与输入及格式约束一致，不证明整个交互状态机正确。未做浏览器交互验收和新增实机按键验收。原始备份及派生文件 SHA-256 统一在项目 `SHA256SUMS` 中。
